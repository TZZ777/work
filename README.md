# 通用文件重命名工具

这是一个专门为办公文档管理设计的自动化重命名工具。它能够根据预设的规则，自动在复杂的文件夹结构中识别目标文件，并为其添加统一的标签，最后将所有处理后的文件归集到一个地方，极大提高文件整理效率。

## 文件夹结构说明

在运行脚本前，请确保您的文件夹布局如下：

```text
项目根目录/
├── RenameToolWin.exe             # 核心工具文件(Windows)
├── RenameToolMac                 # 核心工具文件(MacOs)
├── data/               # 【输入】将待处理的材料包文件夹放在这里
└── output/             # 【输出】处理后的结果会自动生成在这里
    └──[项目名称]/       # 保持原结构的重命名后的文件
```

## 使用步骤

1.  **准备数据**：把您要整理的文件夹（例如“XX公司材料包”）直接复制到 `data` 文件夹里。
2.  **运行工具**：双击运行 
    *   MacOs:`RenameToolMac`
    *   Windows:`RenameToolWin.exe`。
3. **开始**
    *   点击开始重命名后自动处理
    *   请确保data文件夹下有待处理的材料包文件夹
3.  **查看结果**：
    *   打开 `output` 文件夹，您会看到一个与原项目同名的文件夹，里面的文件已经加上了标签。

## 小贴士

*   **安全保护**：脚本不会修改 `data` 里的原始文件，所有的操作都在 `output` 副本中进行。
*   **防止重复**：如果文件名里已经包含 `#` 号，脚本会自动跳过，避免重复添加标签。
*   **支持格式**：默认支持 `.pdf`, `.doc`, `.docx`, `.xlsx`, `.png`, `.jpg`, `.jpeg` 等常见办公格式。

**在 Mac 上运行时的必要操作**

    由于打包的文件没有经过苹果的官方签名，Mac 用户在收到文件后通常需要执行以下两步才能运行：

**第一步：赋予执行权限**
    用户需要打开 Mac 的“终端 (Terminal)”，输入 chmod +x （后面加一个空格），然后把 Mac 文件拖进终端窗口，按回车。

    Bash
    chmod +x RenameToolMac文件路径

**第二步：绕过安全检查** 双击运行时如果提示“无法验证开发者”，请按照以下操作：

    在文件上 点击右键，选择 “打开”。

    在弹出的警告框中再次点击 “打开”（这样会强制系统信任该文件）。

    或者前往：系统设置 -> 隐私与安全性 -> 仍要打开。
